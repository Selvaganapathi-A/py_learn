| Symbol     | Meaning                          |
| ---------- | -------------------------------- |
| `*`        | any characters, one folder level |
| `**`       | recursive, any depth             |
| `?`        | exactly one character            |
| `[abc]`    | one of these characters          |
| `[0-9]`    | digit range                      |
| `*.ext`    | all files with .ext              |
| `**/*.ext` | recursively match extension      |
